# pipeline — group-reviewed notebooks

The shared story of the analysis, not every experiment the team tried. Each notebook runs top to
bottom from the repository root against the [`gammas`](../gammas/) package and the data described in
[`data/README.md`](../data/README.md).

**[`02_canonical_analysis_and_slides.ipynb`](02_canonical_analysis_and_slides.ipynb) is the canonical
source of every number in the project**; the results table that transcribes them, with protocol, `n`
and source cell, is [`docs/final-report.md`](../docs/final-report.md) §5.

| File | What it is |
|---|---|
| [`00_NOTEBOOK_TEMPLATE.ipynb`](00_NOTEBOOK_TEMPLATE.ipynb) | Reusable starting point for a personal sandbox notebook: repository-root discovery, shared-layer import, section skeleton |
| [`01_explore_dataset_b.ipynb`](01_explore_dataset_b.ipynb) | Cohort-B onboarding and EDA on the shared data layer: QC, condition frames, target distribution, an example reconfiguration map |
| [`02_canonical_analysis_and_slides.ipynb`](02_canonical_analysis_and_slides.ipynb) | **Canonical evidence path.** FC reconfiguration prediction, identity-disjoint B→A transfer, d′ target, the activation robustness benchmark, the segregation direction and the presentation figures. Cell 10 is a hard reproduction gate: it asserts r = 0.366 ± 0.01 and stops the run before any interpretation if the pipeline stops reproducing it |
| [`03_method_benchmark_tangent_fc.ipynb`](03_method_benchmark_tangent_fc.ipynb) + [`03_tangent_benchmark_report.md`](03_tangent_benchmark_report.md) | Does a log-Euclidean tangent representation beat the 78-feature fingerprint? Reproduction gate → d′ robustness → development-only CV → identity-disjoint B→A transfer. Verdict: **POSTPONE ADOPTION** — large internal-CV gain, no resolvable transfer gain. The report is generated by the notebook: edit the notebook, never the report |
| [`04_goutham_pipeline_reconciliation.ipynb`](04_goutham_pipeline_reconciliation.ipynb) | Goutham Arcod's `FCM_entropy` functions re-run verbatim on the shared layer, plus the organised brain maps. Explains why the submitted numbers differ from the canonical ones instead of quietly replacing them |

`03` and `04` were promoted from `sandbox/jaime/` with `git mv`; they now live here only, and Git
carries their full history (`git log --follow`). The remaining source notebooks stay in
[`sandbox/jaime/`](../sandbox/jaime/) as the executed exploratory record — `02` recomputes their
results in its own code, so promoting them would duplicate canonical evidence.

How to promote a sandbox notebook into this folder: [`CONTRIBUTING.md`](../CONTRIBUTING.md).
