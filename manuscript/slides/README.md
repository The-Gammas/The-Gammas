# Slides — W3D5 project presentation (archived)

Historical record of **The Gammas'** W3D5 project talk at Neuromatch Academy (July 2026).
The course is over; this folder is kept as the final record of what was presented.

## Contents

- **[`The Gammas - NMA project.pdf`](The%20Gammas%20-%20NMA%20project.pdf)** — the final deck we
  presented. 11 pages: 6 spoken (cover/team · introduction · methods · results · robustness checks ·
  conclusions) plus 5 backup slides opened only in Q&A. Self-contained — every figure is embedded.
- **[`presenter_guide_w3d5.md`](presenter_guide_w3d5.md)** — per-slide presenter guide, in English:
  concept definitions, how to read each figure, how to interpret each number, ready delivery scripts
  and likely Q&A. The speaker's personal Spanish version was never part of this repository.

## Narrative rules (bind every speaker text)

- We pre-specified **two** predictions; the evidence **held one and refined the other** — never "the
  hypothesis changed".
- The B→A result is an **identity-disjoint transfer within the same HCP study**, not an independent or
  external validation.
- The ±0.024 on the primary r is a **spread across partitions** (split SD), not a confidence interval.
